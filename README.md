## Featured Projects

### [ER Bikers — Responsive E-Commerce Web Platform](https://github.com/AlexisCORAN/ER-BIKERS)
Responsive e-commerce website built from scratch using semantic HTML5 and modern CSS3 (Flexbox, Grid, keyframe animations, and media queries). Designed for motorcycle riding gear and protective accessories, focusing on clean UI layout, cross-browser compatibility, mobile responsiveness, and on-page SEO asset optimization.

---

### [SistemaEscuela — Transactional Academic Management System](https://github.com/AlexisCORAN/SistemaEscuela)
Enterprise-grade desktop system built with Java Swing and SQL Server using a layered MVC + Service/DAO architecture. Implements custom ACID transaction management (`TransactionRunner`), automated SQL triggers for audit logging and historical grade locking, and aggregation-based reporting (`SUM`/`HAVING`) for academic risk detection.

---

### [Veterinary Appointment Manager — Java Desktop & Data Structures](https://github.com/AlexisCORAN/Proyecto-Veterinaria)
Desktop management system built in Java Swing implementing custom linear and non-linear data structures from scratch (linked lists, queues, stacks, and binary search trees) without relying on built-in collection frameworks. Features object binary serialization for persistent local storage and modular 3-tier architecture.

---

### [AirBnB Clone — Full-stack booking platform](https://github.com/AlexisCORAN/AirBnB_clone_v4)
Multi-phase full-stack replica of the Airbnb platform. Built a custom CLI console in Python to manage persistent objects (users, places, reviews) via a JSON storage engine and MySQL relational database. Includes a complete OOP model hierarchy, PEP8-compliant codebase, and unit test suite covering all models and storage methods.

**6 contributors across multiple development phases**

### [WatchPets — Real-time pet alert mobile app](https://github.com/AlexisCORAN/watchpets_app)
Cross-platform iOS/Android app built with Flutter and Firebase. Users can send geolocated alerts to nearby contacts when a pet goes missing — including full pet profile, live Google Maps location, and optional message. Supports Facebook OAuth and a real-time alert feed ordered by recency.

---

### [Simple Shell — UNIX command interpreter in C](https://github.com/AlexisCORAN/simple_shell)
Custom shell built from scratch in C with zero external libraries. Implements process creation via `fork`/`execve`, command parsing, environment variable handling, and interactive/non-interactive modes. Compiled with strict GCC flags (`-Wall -Werror -Wextra -pedantic`). Output matches `/bin/sh` exactly.
